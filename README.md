One sentence of horror: a smart speaker answers in the owner's own voice.

## Entry

> I asked the speaker to play white noise, and it answered in my own voice: 'You're the only one still awake.'

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
python3 main.py
```
